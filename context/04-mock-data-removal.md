# Mock Data Removal

## Issue
The platform was rendering fake data (like a dummy Google Senior SWE interview) and fake questions instead of the actual data generated by the backend.

## Solution
1. **Backend Dashboard**: Removed the script in `analytics.controller.ts` that artificially injected a hardcoded mock interview into the database if the user had 0 interviews. The dashboard now accurately reflects an empty state until real interviews are completed.
2. **Frontend Questions**: Removed the hardcoded `mockAIQuestions` array in `frontend/src/app/interviews/live/[id]/page.tsx`. The initial greeting is now dynamically generated based on the user's selected config (`company` and `role`).
